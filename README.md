# AI Recruitment Agent

An end-to-end AI-powered recruitment platform that automates candidate interviewing, evaluation, and report generation.

## Overview

AI Recruitment Agent acts as an intelligent virtual recruiter capable of screening resumes, conducting dynamic voice interviews, evaluating candidates in real time, and generating detailed hiring reports — all without manual recruiter involvement.

---

## Features

### Resume Screening
- Upload resumes in PDF or DOCX format
- Automatic extraction of name, email, skills, experience, and education using HuggingFace NER
- Keyword-based skill matching against job descriptions
- Instant match score with reasons for selection or rejection

### AI Voice Interview
- Real-time voice interview using browser Speech Recognition (STT)
- Human-like AI voice responses via ElevenLabs TTS
- Adaptive questions generated by Google Gemini based on resume and job role
- Dynamic follow-up questions based on candidate answers
- Skip question and type answer options
- 10 questions per interview, ~10-15 minutes duration

### Evaluation & Reporting
- Per-answer scoring (technical, communication, confidence, problem solving)
- RAG-based answer verification using ChromaDB knowledge base
- Final report with overall score, strengths, weaknesses, and hiring recommendation
- PDF report generation
- Visual score breakdown with bar charts

### Admin Dashboard
- Create and manage job roles with full job descriptions
- View all candidates with match scores
- Expand individual candidate interview scores
- Delete candidates and their data
- Role-based access control (admin vs user)

### Authentication
- JWT-based login and signup
- Users can sign up with any email and password
- Session persistence via localStorage

## Tech Stack

### Backend
- **FastAPI** — REST API and WebSocket server
- **SQLAlchemy** — ORM with SQLite database
- **HuggingFace Transformers** — Local NER model for resume parsing (dslim/bert-base-NER)
- **Google Gemini** — Question generation, answer evaluation, report generation
- **ChromaDB** — Vector database for RAG knowledge base
- **Sentence Transformers** — Local embeddings (all-MiniLM-L6-v2)
- **ElevenLabs** — Text-to-speech for AI interviewer voice
- **ReportLab** — PDF report generation
- **JWT / Passlib** — Authentication and password hashing

### Frontend
- **Next.js** — React framework
- **Web Speech API** — Browser-based speech recognition (Chrome only)
- **Recharts** — Score visualization charts
- **Axios** — API communication
- **WebSocket** — Real-time interview communication

### Infrastructure
- **Docker + Docker Compose** — Containerized deployment
- **SQLite** — Lightweight database (upgradeable to PostgreSQL)

## Getting Started

### Prerequisites
- Docker Desktop installed and running
- Google Chrome (required for Web Speech API)
- API keys for Google Gemini and ElevenLabs

### 1. Clone the repository

```bash
git clone https://github.com/pulkitb36/ai-recruitment-agent.git
cd ai-recruitment-agent
```

### 2. Set up environment variables

Create `backend/.env`:

```env
OPENAI_API_KEY=disabled
GEMINI_API_KEY=your_gemini_api_key_here
ELEVENLABS_API_KEY=your_elevenlabs_api_key_here
DATABASE_URL=sqlite:///./recruitment.db
SECRET_KEY=your_random_secret_key_here
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=60
CHROMA_DB_PATH=./chroma_db
WHISPER_MODEL=base
MAX_QUESTIONS=10
MAX_INTERVIEW_MINUTES=15
```

Get your free keys:
- **Gemini** — `aistudio.google.com` (free, no card required)
- **ElevenLabs** — `elevenlabs.io` (free tier — 10,000 chars/month)

### 3. Install frontend dependencies

```bash
cd frontend
npm install axios recharts
cd ..
```

### 4. Build and run with Docker

```bash
docker-compose up --build
```

Wait for both services to show as ready:
backend-1   | INFO: Uvicorn running on http://0.0.0.0:8000
frontend-1  | ✓ Ready in Xs

### 5. Seed the knowledge base (first time only)

In a second terminal:

```bash
docker-compose exec backend python seed_kb.py
```

### 6. Open the app

| Service | URL |
|---|---|
| App | http://localhost:3000 |
| API Docs | http://localhost:8000/docs |

## Usage

### As Admin
1. Go to `http://localhost:3000/login`
2. Login with username `admin` and password `admin123`
3. Go to **Job Roles** tab → add roles with title and full job description
4. Go to **Candidates** tab → view all candidates, expand scores, delete entries

### As Candidate
1. Go to `http://localhost:3000/signup` and create an account
2. Select a job role from the dropdown
3. Upload your resume (PDF or DOCX)
4. Click **Screen candidate** to see your match score
5. Click **Start AI Interview**
6. Allow microphone access in Chrome
7. Click **Start Interview** and speak your answers
8. View your detailed report after the interview

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| POST | `/api/auth/signup` | Create new user account |
| POST | `/api/auth/login` | Login and get JWT token |
| POST | `/api/upload-resume` | Upload and parse resume |
| POST | `/api/start-interview/{id}` | Create interview session |
| WS | `/ws/interview/{id}` | Live interview WebSocket |
| GET | `/api/report/{session_id}` | Get interview report |
| GET | `/api/candidates` | List candidates (role-based) |
| DELETE | `/api/candidates/{id}` | Delete candidate (admin) |
| GET | `/api/roles` | List available job roles |
| POST | `/api/roles` | Create job role (admin) |
| DELETE | `/api/roles/{id}` | Delete job role (admin) |

## Environment Variables

| Variable | Description | Required |

## Known Limitations

- Web Speech API only works in **Google Chrome**
- **ElevenLabs free tier** limited to 10,000 characters per month
- Gemini free tier limited to 60 requests per minute
- Whisper STT not installed in Docker by default — uses browser STT instead
